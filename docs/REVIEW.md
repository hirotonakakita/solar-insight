# 整理の根拠と残作業

## 版の扱い

ユーザーによればDドライブ一式は旧版の可能性があります。new002という名前は系列内の候補で、プロジェクト全体の最終版を保証しません。D版から検出関数を抽出し、Z版との照合は未完了です。原本は変更していません。

## 確認した問題

- 旧predict_flare.pyはmodel/deviceと重み読込が未定義。新版では明示ロードとevalを実装。
- 推論の固定除算は標準化済み学習CSVと不一致。生値/標準化値から数値変換を復元。重みとの由来一致は未確認。
- train.pyは全データの学習損失で停止し、訓練データ上のRecallを計算。検証データなし。最良モデルを再読込せず最終状態を保存。
- train_flare_predictor_768.pyは別のTensorFlow系モデル。特徴量にflare_M_count/flare_X_countを使用し、分類ラベルも同日のフレアを表すため、予測性能に使うには目的変数の情報漏洩を除く必要あり。
- evaluate_model.py、evaluate_model_fixed_v2.py、旧fixed.pyに構文エラー。
- 従来のP角処理は太陽軸方向の妥当性と時刻系が未確認。新CLIでは方位線を提供せず、検出に範囲を限定。
- 旧注釈処理はログCSVを重複排除して上書き。新CLIは原ログを変更しない。
